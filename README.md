# Radio

## Requirements

- Node.js 22.12 or newer
  also supports Node.js 20.19+
- npm 10.8 or newer.

## How to run

Before running the backend, make sure you have a .env in backend file.

```bash
cd backend
npm i
npm run dev
```

npm i in the backend, it automatically runs database migrations.

```bash
cd frontend
npm i
npm run dev
```
